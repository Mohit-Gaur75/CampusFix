# CampusFix

CampusFix is a hackathon MVP: a campus issue-management platform.
It streamlines reporting and tracking for campus issues like broken lights, Wi-Fi outages, and maintenance requests, providing authorities with a clear, prioritized dashboard.

## Stack
- **Frontend**: React + Vite + Tailwind CSS
- **Backend**: Node.js + Express
- **Database**: MongoDB Atlas
- **Auth**: JWT

## Folder Structure
- `/client`: React frontend
- `/server`: Node/Express backend
- `/docs`: Project documentation and blueprints

## How to Run

### Backend
\`\`\`bash
cd server
npm install
# Ensure you have a .env file configured
npm run dev
\`\`\`

### Frontend
\`\`\`bash
cd client
npm install
# Ensure VITE_API_URL is set in .env
npm run dev
\`\`\`
